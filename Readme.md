# Project Description

This project is structured with multiple branches to showcase different implementations of the same layout. You are currently on the `develop` branch. To explore the various versions of the project, switch to one of the following child branches:

-   **`vanilla`**: Implementation using plain HTML and CSS.
-   **`sass`**: Implementation using SASS for styling.
-   **`tailwind`**: Implementation using Tailwind CSS.

Use Git commands to navigate between branches and review the corresponding versions.

```bash
# Example: Switch to the 'vanilla' branch
git checkout vanilla
```

Feel free to explore and compare the different approaches!
