📄 Description

Construction of a landing page based on the provided designs.

💻 Technologies Used

HTML, CSS (Tailwind CSS), JavaScript.

📋 Requirements - 🛠️ Installation

Tailwind CLI is required to compile `styles.css` file in case of modification of the custom styles. You can install Tailwind with Tailwind CLI using npm with the command `npm install tailwindcss @tailwindcss/cli`. To compile `styles.css` file, run `npx @tailwindcss/cli -i ./css/main.css -o ./css/styles.css --watch` in the terminal.

▶️ Execution

Open `index.html` in a browser to access the site.

🌐 Deployment

To deploy the project, place the `index.html` file along with the 'css' and 'resources' folders on the server.
